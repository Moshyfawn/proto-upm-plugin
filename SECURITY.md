# Security

Only the latest release is supported.

Report a vulnerability privately through [GitHub's security advisories](https://github.com/Moshyfawn/proto-upm-plugin/security/advisories/new) rather than a public issue. Expect a first reply within a week.

Every release ships `upm_tool.wasm.sha256` and a build provenance attestation; verify a download with `gh attestation verify upm_tool.wasm --repo Moshyfawn/proto-upm-plugin`.
